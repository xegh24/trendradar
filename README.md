# Trendradar 2027

Interaktív radar 50 kialakuló globális trendről 12 területen (AI, hardver, közösségi média, appok és játék, fogyasztás, egészség, étel és utazás, pénz, energia, munka, mobilitás, makrogazdaság).

Minden trendnél: érettség (gyenge jel → fősodor), becsült hatás, kulcsszámok, „miért most”, lehetőségek és források. Szűrhető terület, érettség és kulcsszó szerint, egy kapcsolóval csak az indie fejlesztőknek / creatoroknak releváns trendek is megjeleníthetők.

## Használat

Egyetlen önálló HTML-fájl, build nélkül: nyisd meg az `index.html`-t böngészőben, vagy kapcsold be a GitHub Pages-t (Settings → Pages → Branch: `main`, mappa: `/`).

## Adatok

Állapot: 2026. október 27. A számok a kártyákon linkelt forrásokból származnak (Gartner, IMF, Sensor Tower, Counterpoint, BloombergNEF, Mintel, PwC és mások). Az érettségi besorolás és a hatás-pontszám szerkesztői becslés.
